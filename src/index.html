Il file viene cifrato nel tuo browser con age. Se preferisci, cifralo tu con il comando qui sotto. 

age -r __RECIPIENT__ -o file.age file

Per l'anonimato usa Tor Browser e il nostro onion service: __ONION__.

Send us a file

The file is encrypted in your browser with age. If you prefer, encrypt it yourself with the command below. 

age -r __RECIPIENT__ -o file.age file

For anonymity use Tor Browser and our onion service: __ONION__.

JavaScript disattivatoJavaScript is disabled

Serve JavaScript per cifrare nel browser (in Tor Browser il livello "Il più sicuro" lo blocca). Se hai già cifrato il file con age, spunta la casella e caricalo comunque. JavaScript is required for client-side encryption (Tor Browser's "Safest" level blocks it). If you pre-encrypted the file with age, tick the box and upload anyway.
